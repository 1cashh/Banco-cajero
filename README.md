# Sistema bancario en java

Programa realizado en Java utilizando Programación Orientada a Objetos (POO).

## Descripción

El programa simula un cajero bancario donde se pueden realizar operaciones sobre distintos clientes y tipos de cuentas.

## Funcionalidades

- Depositar dinero
- Giro en Cuenta Corriente
- Giro en Cuenta de Ahorro
- Mostrar saldo
- Menú interactivo tipo cajero
- Validación de tipo de cuenta

## Tipos de Cuenta

### Cuenta Corriente
- Permite giros
- Cobra comisión del 1% por retiro

### Cuenta de Ahorro
- Solo permite retirar hasta el 75% del saldo

## Tecnologías

- Java
- IntelliJ IDEA
